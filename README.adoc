= page-edit
:description: Antora extension that bakes an Edit control (with VCS provider mark) into the page-context lead zone at build time.
:page-audience: Antora hub authors who want Edit beside page metadata without runtime icon JS
:page-usage-context: Register under `antora.extensions` (pairs with page-context + a theme such as Valentus)
:page-orig-author: Ryan Johnson
:page-last-author: Cursor agent on behalf of Ryan Johnson
:page-last-edited: 2026-09-09

Injects a baked **Edit** control into the `@antora-supplemental/page-context` lead panel (or as a standalone actions aside when no lead exists). The VCS provider mark is chosen from the edit URL **at site build time** — no `site-vcs-icons.js` rewrite for Antora pages.

Also exports `vcsIconIdFromUrl` / `adtVcsIconIdHelper` for UI themes that want the same mapping in Handlebars (e.g. header repo button).

== Install

[source,bash]
----
pnpm add -D github:antora-supplemental/page-edit#main
----

== Playbook

[source,yaml]
----
antora:
  extensions:
    - '@antora-supplemental/page-edit'
asciidoc:
  extensions:
    - '@antora-supplemental/page-context'
----

Optional config:

[source,yaml]
----
antora:
  extensions:
    - require: '@antora-supplemental/page-edit'
      forceShow: true  # same idea as FORCE_SHOW_EDIT_PAGE_LINK
----

== Behavior

* Runs on `pagesComposed`.
* Uses Antora `src.editUrl` when present (and origin is not private, unless `forceShow` / `FORCE_SHOW_EDIT_PAGE_LINK`).
* Falls back to `src.fileUri` for local previews when not in `CI`.
* Markup: `<aside class="page-context page-context-actions">…inline SVG… Edit</aside>` inserted as the first child of `.page-context-lead` when that aside exists.
* Idempotent if `page-context-actions` is already present.

== UI helper (optional)

Themes may re-export the helper into `helpers/adt-vcs-icon-id.js`:

[source,js]
----
'use strict'
module.exports = require('@antora-supplemental/page-edit').adtVcsIconIdHelper
----

[source,hbs]
----
<img src="{{{uiRootPath}}}/img/vcs/{{adt-vcs-icon-id page.origin.webUrl 'repo'}}.svg" alt="" />
----
