= page-edit
:description: Antora extension that bakes a Source line (View | Edit, with VCS provider mark) directly under the page title at build time.
:page-audience: Antora hub authors who want source links beside page metadata without runtime icon JS
:page-usage-context: Register under `antora.extensions` (pairs with page-context + a theme such as Valentus)
:page-orig-author: Ryan Johnson
:page-last-author: Cursor agent on behalf of Ryan Johnson
:page-last-edited: 2026-09-10

Injects a **Source: View | Edit** line directly under the page title, before the @antora-supplemental/page-context lead (byline + metadata table). The line is never a metadata-table row, and placement is the same on every page, whether or not it has a lead. The VCS provider mark is chosen from the edit URL **at site build time** — no `site-vcs-icons.js` rewrite for Antora pages.

Also exports `vcsIconIdFromUrl` / `adtVcsIconIdHelper` for UI themes that want the same mapping in Handlebars (e.g. header repo button).

== Install

[source,bash]
----
pnpm add -D github:antora-supplemental/page-edit#v0.2.3
----

== Playbook

[source,yaml]
----
antora:
  extensions:
    - '@antora-supplemental/page-edit'
asciidoc:
  extensions:
    - '@antora-supplemental/page-context'
----

Optional config:

[source,yaml]
----
antora:
  extensions:
    - require: '@antora-supplemental/page-edit'
      forceShow: true  # same idea as FORCE_SHOW_EDIT_PAGE_LINK
----

== Behavior

* Runs on `pagesComposed` (after Antora UI compose — `page.contents` is often a full HTML document).
* Uses Antora `src.editUrl` when present (and origin is not private, unless `forceShow` / `FORCE_SHOW_EDIT_PAGE_LINK`).
* Falls back to `src.fileUri` for local previews when not in `CI` (Edit only — no View link for `file://`).
* Markup: `<div class="page-context-source-line"><span class="page-context-source-key"><span class="page-context-source-label">Source:</span>{icon}</span> <span class="page-context-source-actions">View | Edit</span></div>`.
* The VCS provider mark follows the **Source:** label (not a button; does not replace the word). View and Edit are plain text links only.
* View URL derived from Edit when possible: GitHub `/edit/` → `/blob/`, GitLab `/-/edit/` → `/-/blob/`; when Antora supplies a blob URL (tag-pinned sources), Edit is derived the other way.
* Idempotent if `page-context-source-actions` or legacy `page-context-actions` is already present.
* Placement: after `.valentus-page-header` (or legacy `.adt-page-header`, else the first `<h1>`) inside `<article class="doc">`, so the order is title → Source line → byline → metadata table.
* **Never** prepends markup before `<!DOCTYPE>` / the site header. Fragments without an article get the Source line prepended (the theme renders the title above `page.contents`).

== UI helper (optional)

Themes may re-export the helper into `helpers/valentus-vcs-icon-id.js`:

[source,js]
----
'use strict'
module.exports = require('@antora-supplemental/page-edit').adtVcsIconIdHelper
----

[source,hbs]
----
<img src="{{{uiRootPath}}}/img/vcs/{{valentus-vcs-icon-id page.origin.webUrl 'repo'}}.svg" alt="" />
----

== Future

Edit may later open **Antora Live** (DB-backed concurrent AsciiDoc authoring) when a hub configures a Live base URL, instead of — or in addition to — the forge edit URL.
Until then, this package only bakes static VCS **View | Edit** links. See https://docs.antora-supplemental.org/docs/live-docs/[Live docs] and https://github.com/antora-supplemental/antora-live[antora-live].
