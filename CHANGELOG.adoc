= Changelog

== 0.3.0 - 2026-10-21

* **Source line under the title:** View | Edit is now a `.page-context-source-line` (VCS mark + `Source:` + links) inserted directly after the page title block, before the page-context lead. It is no longer a `.page-context-source-row` in the metadata table.
* **One placement everywhere:** pages with and without a page-context lead get the same order (title, Source line, byline, metadata table). Fixes Source appearing above the title on pages without a lead: placement was keyed on `adt-page-header`, so the renamed `valentus-page-header` fell through to "right after `<article>`".
* Title block detection accepts `valentus-page-header` and legacy `adt-page-header`, and falls back to the first `<h1>`.
* Removed `buildSourceRowHtml` / `buildLeadSourcePanelHtml` (replaced by `buildSourceLineHtml`). Still idempotent against already-baked rows, lines, and legacy actions asides.
* Pairs with page-context **0.7.1** (no empty component-home lead shell) and Valentus `.page-context-source-line` styles.

== 0.2.5 - 2026-10-17

* **Tag-pinned content sources:** when Antora sets `src.editUrl` to a forge **blob** URL (tags and other non-branch refs), derive **View** from that URL and point **Edit** at the matching `/edit/` (or GitLab `/-/edit/`) link so demo-pages and other tagged `demo-data` fixtures show View | Edit again.

== 0.2.4 - 2026-09-15

* **Component-home Source row:** idempotency no longer treats page-context CSS class names (`.page-context-source-actions`) as an already-injected Source row. Empty lead shells on Antora component start pages get View | Edit again.

== 0.2.3 — 2026-09-10

* **Safe inject on composed pages:** Antora `pagesComposed` runs after UI compose, so `page.contents` is often a full HTML document. Never prepend View|Edit before `<!DOCTYPE>` / the top navbar.
* When no lead exists, insert a `.page-context-lead` panel (Source row) inside `<article class="doc">` after the page header; fragments without a lead get the same lead shell prepended.
* Pairs with page-context **0.6.4** component-home lead shell.

== 0.2.2 — 2026-09-10

* Document Future: Edit may target Antora Live when configured; clarify View | Edit remains forge links until then.

== 0.2.1 — 2026-09-10

* Place the VCS provider mark on the **Source** key cell (before the label), not on the Edit link.
* Value cell is text-only `View | Edit` (no icon on either link; View still before Edit).
* When creating a lead table for a byline-only aside, wrap it in `.page-context-panel` so page-context lead nesting stays intact.

== 0.2.0 — 2026-09-10

* Inject **View | Edit** as a lead-table **Source** key/value row (not a floating actions aside inside the lead).
* Derive View (blob) URLs from Edit URLs when possible (`/edit/` → `/blob/`, GitLab `/-/edit/` → `/-/blob/`).
* Keep a legacy `.page-context-actions` aside only when no page-context lead exists.

== 0.1.0 — 2026-09-09

* Initial release: bake Edit + inline VCS provider SVG into the page-context lead zone on `pagesComposed`.
* Export `vcsIconIdFromUrl` / `adtVcsIconIdHelper` for theme Handlebars helpers (header marks without runtime JS).
